# Git Commit

git-operations-expertサブエージェントを使用して、ステージング済みの変更を分析し適切なコミットメッセージを自動生成してコミットを実行する。

## サブエージェントへのプロンプト例

```
ステージングされている変更を分析し、適切なコミットメッセージを作成してコミットを実行してください。

手順:
1. git status, git diff --staged, git log --oneline -10 を並列実行
2. ステージング済み変更がなければユーザーに通知して終了
3. 変更内容を分析してコミットメッセージを作成:
   - 「何を」より「なぜ」を重視
   - 簡潔に1〜2文の日本語で要約
   - リポジトリの既存コミットメッセージスタイルに従う
   - .env や credentials.json 等がステージングされている場合は警告して停止
4. git commit -m "<生成したメッセージ>" でコミット実行
5. git status と git log -1 で結果確認
```

## pre-commitフック失敗時の対応

1. フックによって修正されたファイルを確認
2. 以下を両方確認した場合のみamendが安全:
   - `git log -1 --format='%an %ae'` で自分のコミットか確認
   - `git status` で「Your branch is ahead」を確認（未プッシュ）
3. 安全な場合: `git add <修正ファイル> && git commit --amend --no-edit`
4. 安全でない場合: 新しいコミットを作成

## 注意事項

- ステージングされていない変更はコミットに含まれない
- 機密情報（APIキー等）を含むファイルはコミットしない
