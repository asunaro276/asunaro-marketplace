# daily

Claude Codeの利用履歴を解析し、毎日の日報を自動生成するプラグイン。

## 特徴

- **高速並列処理**: GoのゴルーチンでセッションファイルをCPUコア数に応じて並列解析
- **トークン効率**: Claudeに渡すのは軽量なJSONサマリーのみ（生ファイルを直接読ませない）
- **クロスプラットフォーム**: Windows / macOS / Linux（WSL含む）対応
- **ポータブル**: プラグイン1つで複数PCに持ち運べる

## 必要要件

- [Go](https://go.dev/dl/) 1.21 以上（初回のみバイナリコンパイルに使用）
- Claude Code / Coworkがインストールされていること

## コンポーネント

| コンポーネント | 場所 | 役割 |
|---|---|---|
| スキル: `daily-report` | `skills/daily-report/` | 日報生成のメインスキル |
| Goスクリプト: `cc-summarizer` | `scripts/cc-summarizer/main.go` | セッション並列解析エンジン |

## 使い方

Claudeに以下のように話しかけるだけ：

- 「日報を作って」
- 「今日のClaude Code利用状況をまとめて」
- 「デイリーレポートを生成して」
- 「昨日の日報：2026-03-27」（日付指定も可）

初回実行時にGoバイナリが自動コンパイルされます（数秒かかります）。

## 仕組み

```
Claude からの指示
      ↓
cc-summarizer（Goバイナリ）
  ~/.claude/projects/ を並列スキャン
  当日のセッションJSONLを解析
  → 軽量サマリーJSONを出力
      ↓
Claude が解釈
  セッション内容・ツール使用・トークン数を分析
  → 日本語日報を生成
```

## データ保存場所

解析対象：`~/.claude/projects/**/*.jsonl`

日報の保存先（任意）：`~/日報/日報_YYYY-MM-DD.md`

## プライバシー

- セッションファイルはローカルのみで処理（外部送信なし）
- 機密情報（APIキー等）はスキルが自動的にマスクします
